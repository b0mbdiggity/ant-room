# ANT ROOM · 지하 관측소

게스트 개미들이 한 방에 모여 데모 캔들 차트를 보는 Next.js 앱입니다.

## 로컬 실행

Node.js 22에서 `npm ci`를 실행합니다. `.env.example`을 `.env.local`로 복사하고 Supabase 프로젝트 URL과 공개용 publishable 키를 설정한 뒤 `npm run dev`를 실행합니다. 새 Supabase 프로젝트에서는 `supabase/migrations`의 SQL을 순서대로 적용합니다.

- WASD로 이동하고 화면을 드래그해 시점을 돌립니다. 터치 기기에는 방향 버튼이 표시됩니다.
- 전광판에서 캔들을 누르거나 오른쪽 슬라이더를 움직여 반응할 캔들을 선택합니다.
- 캔들 반응은 게스트당 캔들마다 하나입니다. 다른 이모지를 고르면 기존 반응을 바꿉니다.
- 채팅은 최대 180자, 게스트당 3초 간격입니다. 같은 문장은 30초 뒤에 다시 보낼 수 있습니다.

## 방 운영

Supabase의 `public.rooms`에서 종목을 추가하거나 방 정원을 변경하면 앱이 재배포 없이 반영합니다. 종목마다 동일한 데모 차트가 표시됩니다.

```sql
insert into public.rooms (ticker, title, capacity) values ('000660', 'SK하이닉스', 100);
update public.rooms set capacity = 80 where ticker = '005930';
```

정원은 방마다 1~100명입니다. 현재 점유 수보다 낮게 줄이는 작업은 데이터베이스가 거부합니다. 명시적으로 나가면 즉시 자리가 풀리고, 연결이 끊기면 마지막 갱신 후 최대 90초에 만료됩니다. 이동과 시점은 각 브라우저에서 처리하며, 다른 게스트는 배정 좌석에 표시됩니다. 좌석, 채팅, 반응 변경은 Supabase Realtime에서 수신합니다.

게스트 토큰은 탭 세션에 저장됩니다. 로그인 기능은 이후 추가할 수 있으며 현재 기능은 게스트로 이용할 수 있습니다.
